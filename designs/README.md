# designs/

Drop reference designs here, one folder per page:

```
designs/
  home/
    index.html        exported HTML (Tailwind / Stitch / Figma export)
    screenshot.png    optional full-page screenshot
    notes.md          optional: which page it is, behaviour, dynamic data, breakpoints
```

Then ask the agent, for example: "Build the hero and features sections from designs/home" or run `/build-section designs/home`.
Mention (once) if known: Elementor version, Elementor Pro yes/no, WooCommerce yes/no, active theme, RTL/Persian or not.
